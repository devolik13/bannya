## Как с этим работать в Claude Code

- Репозиторий — **статичный экспорт Tilda**. Правки в HTML здесь — это полигон для проверки,
  а не боевой сайт. Каждая готовая правка затем **вручную переносится в редактор Tilda**
  (куда именно — указано в каждой задаче). После переноса сайт экспортируется заново и пушится
  сюда, Claude Code сверяет результат.
- Полигон разворачивается на Vercel (задача 0). Копия на Vercel **не должна индексироваться**.
- Карта URL → файл: `htaccess` (строки `RewriteRule ^slug$ pageNNN.html`).
  Ключевые файлы:
  - `page30466466.html` — главная `/`
  - `page30467207.html` — `/ochakovo` (3,9 МБ)
  - `page30491483.html` — `/lobnenskaya` (3,1 МБ)
  - `page67983889.html` — `/index` (черновик новой главной, noindex)
  - `page67884573.html` — `/blog` (noindex), `page71967791.html` — `/reviews` (noindex),
    `page67989845.html` — `/dishes` (noindex), `page68024647.html` — `/guest_card` (noindex)
  - `page70296979.html` — `/quiz` (чужой description), `page138412046.html` — `/prequiz`
- Команда для проверки факта «что видит ИИ»: вытащить из страницы только текст без скриптов и стилей
