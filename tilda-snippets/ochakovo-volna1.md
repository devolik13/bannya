# Очаково — волна 1: пакет для Tilda

Касается только страницы **/ochakovo**. Лобненскую, главную, общие шапку/подвал и настройки сайта не трогаем.

## 1. Микроразметка комплекса (JSON-LD)

**Что это:** невидимая для посетителей «карточка» комплекса для поисковиков и ИИ: название, адрес,
часы работы, ссылки на Яндекс Карты и 2ГИС, 11 срубов с ценой за час и вместимостью.
На внешний вид страницы не влияет.

Основной номер в разметке: +7 (495) 795-00-01 (подтверждён владельцем). Код готов к вставке без изменений.

**Куда вставить:**
1. Tilda → проект → страница «Очаково» (/ochakovo) → «Настройки» страницы.
2. Вкладка «Дополнительно» → поле «HTML-код для вставки внутрь head».
3. Вставить **всё** содержимое файла `ochakovo-jsonld.html` целиком, от `<script` до `</script>`.
   Если в поле уже есть код — вставить ниже него, ничего не удаляя.
4. Сохранить → «Опубликовать» страницу.

**Как проверить себя:**
1. https://validator.schema.org → вкладка «Фрагмент кода» → вставить содержимое файла → «Проверить».
   Должно быть 0 ошибок (предупреждения допустимы).
2. После публикации: Яндекс Вебмастер → Инструменты → «Валидатор микроразметки» → адрес
   `https://banniy-dvor.ru/ochakovo` → должны появиться `Organization` и `LocalBusiness`.

**Важно:** цены в разметке должны совпадать с ценами на странице. Если цена сруба меняется на сайте —
нужно поменять её и в этом коде (или сказать нам, мы пришлём новую версию).

**Куда:** Tilda → страница «Очаково» (/ochakovo) → «Настройки» страницы.
