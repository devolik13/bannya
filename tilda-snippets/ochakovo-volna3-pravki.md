# Очаково — волна 3: дальнейшие шаги

Страница **banniy-dvor.ru/ochakovo/srub-knyazheskiy** получилась хорошо: заголовок, тексты, блок фактов,
оснащение, «хлебные крошки», ссылки — всё по заданию. На странице Очаково сделано: баннер с задержкой 20 секунд,
ссылки на правила в подвале, плитка «бассейн».

Ниже — что осталось. Порядок важен: шаги 1–4 идут один за другим.

## Шаг 1. Форма бронирования — оставить новую и сделать её общей

Новая форма (с выбором дополнительных услуг и комментарием) лучше старой — оставляем её и используем везде.

1. На странице Очаково сделать **одну общую форму** такого же вида, добавив в неё поле «Выберите сруб»
   со списком всех 11 срубов.
2. Обязательные поля — **только имя и телефон**. Дата, промокод, услуги и комментарий — необязательные.
3. В настройках формы подключить **те же приёмщики данных**, что стояли у старых форм
   (почта, CRM, Telegram — всё, что было). Поле телефона — стандартное поле «Телефон» (по нему заявку видит Calltouch).
4. Все кнопки «Забронировать» на странице Очаково открывают эту общую форму.
5. Остальные 11 форм (по одной на сруб) со страницы Очаково удалить.
6. **Отправить тестовую заявку** со страницы Очаково и со страницы «Княжеский» и убедиться,
   что обе дошли администраторам так же, как раньше.

## Шаг 2. Карточка «Княжеский» ведёт на новую страницу

Сейчас кнопка у карточки по-прежнему открывает всплывающее окно, а на новую страницу с сайта нет ни одной ссылки —
ни гости, ни поисковики на неё не попадут.

1. На странице Очаково у сруба «Княжеский» (в списке срубов и в карточке) заменить ссылку
   `#knyaz` / `#popup:sryb_knyazeskiy` на `/ochakovo/srub-knyazheskiy`.
2. Проверить: клик по карточке открывает новую страницу, а не окно.
3. После этого **удалить со страницы Очаково блок-окно «Княжеского»** (большой Zero Block с описанием сруба
   и блок всплывающего окна, который его показывает). Окно видеотура, если оно отдельное, тоже убрать —
   видеотур теперь на странице сруба.

Ради этого шага всё и делалось: пока окно на странице, она не стала легче (4,2 МБ, как и было).

## Шаг 3. Страница «Княжеский»: настройки

1. **Код разметки.** Настройки страницы → «Дополнительно» → «HTML-код для вставки внутрь head» →
   вставить целиком содержимое файла `ochakovo-srub-knyazheskiy-jsonld.html`. Сейчас кода на странице нет.
2. **Картинка для соцсетей.** Настройки страницы → «Фейсбук и соцсети» → Изображение.
   Сейчас подставилась служебная иконка — при отправке ссылки в мессенджер не будет превью.
   Загрузить фото сруба (бассейн или интерьер), jpg, примерно 1200×630.
3. **Подписи к фото (alt)** — у 22 фото их нет. Примеры: «Сруб Княжеский, бассейн 4×8 м, Банный Двор Очаково»,
   «Сруб Княжеский, парная по-чёрному», «Сруб Княжеский, банкетный зал».
4. Проверить страницу **с телефона**: нет ли горизонтальной прокрутки и наложений текста.

## Шаг 4. Страница «Мужские забавы» — по образцу «Княжеского»

Тексты и файл разметки уже присланы (задание волны 3, файл `ochakovo-srub-muzhskie-zabavy-jsonld.html`).

1. Скопировать страницу «Княжеский», задать адрес `ochakovo/srub-muzhskie-zabavy`.
2. Заменить тексты, фото, видеотур, список оснащения, title и description — по заданию.
3. Вставить код разметки из файла, загрузить картинку для соцсетей, подписать фото.
4. На странице Очаково перевести карточку «Мужские забавы» на новую страницу
   (вместо `#ochakovo_mens` / `#popup:muzhskie-zabavy`) и удалить её окно.
